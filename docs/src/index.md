# Lume UI Language Specification

Lume は、Web UI を宣言的に記述し、HTML + JavaScript + CSS または HTML + JavaScript + CSS + WebAssembly へ直接コンパイルするための UI 言語です。

このサイトは、リポジトリ内の章分割済み Markdown 仕様書をそのまま読みやすい Web ドキュメントとして再構成したものです。左のサイドバーで章を移動しながら読むことを前提にしています。

```txt
overview
  -> foundations
  -> language core
  -> UI / routing
  -> data / FFI
  -> runtime / targets
  -> internals
  -> std modules
  -> tooling
  -> grammar / AST
  -> policy / packaging
  -> compiler / MVP
```

## まず読む順番

1. 基礎
2. 言語コア
3. UI とルーティング
4. データ取得と FFI
5. ターゲットと実行モデル
6. 内部 IR と最適化
7. 標準モジュール
8. ツールと設定
9. 構文と AST
10. ポリシーと配布
11. コンパイラと MVP

## このドキュメントの特徴

- 章番号をそのまま維持しているので、仕様本文と実装の対応が追いやすいです。
- 各章は独立した Markdown ファイルなので、必要な部分だけを素早く読めます。
- 仕様の全体像はこのページでつかみ、詳細は該当章へ移動する流れを想定しています。

## 読み方のコツ

- まずは「基礎」と「言語コア」で、Lume の文法と考え方をつかみます。
- その後に「UI とルーティング」で見た目と遷移を確認すると、全体像がつながりやすいです。
- 仕様の後半は実装・運用寄りなので、必要な章から拾い読みして問題ありません。
